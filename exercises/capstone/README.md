# Capstone: a word counter

One small program, built a step at a time. Every exercise of this topic is a step in the life of the same program, a word counter: it reads text and says how many times each word appears. Each step starts from the finished previous step, so you never face a blank page, and each one asks for one new piece of what the course taught.

The steps: `capstone1` the type and its methods, `capstone2` reading text from a stream, `capstone3` an interface and a fake (and a package of its own, `store`), `capstone4` the whole program with flags and exit codes, `capstone5` counting in parallel without sharing.

The folder of an exercise is the program: several files of one package, as in a real project. The file with the `// I AM NOT DONE` marker is the one to run; the `// TODO:` says which file needs the change.
